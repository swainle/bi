# 地图数据来源与使用限制

`china.json` — 中国省级行政区矢量轮廓（34 个要素），用于看板区域着色与筛选联动。

## 当前状态

| 项 | 情况 |
|---|---|
| 用途 | 内部开发与演示 |
| 来源 | 项目早期整理沿用，来源与授权文件**待补充** |
| 审图号 | **无** |
| 坐标精度 | 省级轮廓，含台港澳，海南省面延伸至南海诸岛 |

## 使用限制

> ⚠️ 本文件不得用于「向社会公开的地图展示」。

依据《地图管理条例》第二十一条、第三十三条，向社会公开的地图须经审核并标注审图号。
内部系统自用不构成「公开」，但仍建议在正式对外发布前完成替换。

## 替换指引（对外发布前必须完成）

1. 从**自然资源部标准地图服务**（bzdt.ch.mnr.gov.cn）下载标准地图成果，或采购具备
   测绘资质的商业数据（高德 / 阿里云 DataV / Mapbox CN）；
2. 在图面右下角渲染审图号（如「GS(2024)xxxx号」）；
3. 保持 JSON 结构不变（`features[].properties.name` 为省名），前端无需改代码；
4. 替换后在本文件补记：来源、获取日期、审图号、授权范围。
