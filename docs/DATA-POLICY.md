# 数据与素材声明

> 本文件说明本仓库包含什么数据、不包含什么数据，以及对外交付时的数据边界。
> 目的是让使用者、客户与尽调方能够快速确认：这套系统**不携带任何第三方平台的真实经营数据**。

---

## 一、仓库内不含真实平台数据

| 类型 | 是否包含 | 说明 |
|---|---|---|
| 拼多多 / 天猫 / 抖音 / 京东的真实经营数据 | **否** | 不出现在仓库，也不随产品分发 |
| 真实商品 ID、真实商品链接 | **否** | 演示数据使用保留号段（见下） |
| 真实商品主图 / 详情图 | **否** | 演示素材为自绘占位图 |
| 用户评论原文、买家信息 | **否** | 演示评论为程序合成的示意文本 |
| 任何个人信息（姓名 / 手机 / 地址） | **否** | 系统不采集 C 端个人信息 |

## 二、演示数据的合成规则（可据此识别）

| 数据集 | 号段 / 规则 | 说明 |
|---|---|---|
| 拼多多榜单（演示） | 商品 ID `700000000001` – `700000000199` | 连续保留号段，一眼可辨 |
| 天猫榜单（演示） | 商品 ID `810000000001` – `810000000199` | 同上 |
| 品牌名 | 「示例品牌甲 / 乙 / 丙 …」 | 非真实商标 |
| 商品标题 | 模板化合成（品类词 + 规格词） | 不对应任何在售商品 |
| 数值指标 | 按合理区间随机生成 | 销量、指数、天数均非真实值 |
| 商品图 | 纯色底 + 品类文字的自绘占位图 | 约 30 KB/张，可直接肉眼区分 |

导入命令见 README「组件库」一节（`scripts.import_rank_board`），数据源为上述演示 CSV。

## 三、客户数据

| 项 | 原则 |
|---|---|
| 存储位置 | 客户自有服务器 / 客户自有数据库，本项目不回收、不上传 |
| 传输 | 除客户自行配置的 LLM 接口外，无任何外发请求 |
| AI 能力 | 启用时仅发送表结构元数据与查询意图，不发送明细数据；可完全关闭 |
| 账号体系 | 客户自建管理员，口令由客户设定，不设后门账号 |
| 删除 | 客户可自行清库；本项目不保留副本 |

## 四、地图数据（需注意）

`backend/app/maps/china.json` 为中国轮廓矢量数据，用于内部分析场景的区域着色。

> ⚠️ **当前状态：开发用途，未取得审图号。**
> 该底图不得用于「向社会公开的地图展示」。依据《地图管理条例》，公开使用的地图
> 须送审并标注审图号。正式对外发布前，应替换为自然资源部标准地图服务
> （bzdt.ch.mnr.gov.cn）的成果，或采购具备测绘资质的数据源，并在图面标注审图号，
> 同时在本目录补充 `SOURCE.md` 记录来源与授权。

## 六、对外交付清单

交付给客户或用于演示时，请确认：

- [ ] 不包含 `市场部BI看板模板/` 中的原始平台导出文件
- [ ] 不含真实商品图（所有商品图应为自绘占位图）
- [ ] 不含真实商品链接（`yangkeduo.com`、`detail.tmall.com` 等应替换为示例域名）
- [ ] 不含采集方法论文档（抓取时间、字段清单、接口路径）
- [ ] 地图底图已替换为标准地图或已注明内部用途
- [ ] `LICENSE`、`THIRD-PARTY-NOTICES.md`、本文件随包提供

## 七、声明

本系统是**分析工具**，不提供数据采集能力，也不内置任何平台的数据接口凭证。
使用者应确保其接入的数据具备合法来源与使用授权；因数据来源引发的责任，
由数据接入方自行承担。
