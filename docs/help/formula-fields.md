# 公式字段

公式字段使用同一行的已有列计算一个新值。例如，销售额为 100、成本为 60 时，`revenue - cost` 得到利润 40。

## 创建与测试

1. 进入 **数据集 → 编辑 → 字段 → 添加公式字段**。
2. 填写唯一的字段名，例如 `利润`。
3. 输入 SQL 表达式，或点击可用列插入列名。
4. 选择角色、类型，以及是否允许筛选和分组。
5. 点击 **测试** 检查语法、引用列和允许的函数。
6. 测试通过后点击 **保存**，在数据预览或图表中选择该字段。

只填写表达式，不需要 `SELECT`、`FROM` 或 `AS`。字段名同时作为结果列名和显示名称。

**测试不保存字段，也不逐行验证全部计算结果。** 测试通过不保证所有行都能执行成功，除零、无效日期、无法转为数字的文本等问题仍需在预览中检查。修改表达式后需要重新测试。

## 加减乘除

| 用途 | 表达式 | 推荐类型 |
| --- | --- | --- |
| 利润 | `revenue - cost` | numeric |
| 总费用 | `cost + promotion_fee` | numeric |
| 商品金额 | `price * quantity` | numeric |
| 单件销售额 | `revenue * 1.0 / NULLIF(quantity, 0)` | numeric |
| 利润率 | `(revenue - cost) * 1.0 / NULLIF(revenue, 0)` | numeric |

先乘除，后加减，使用括号控制顺序。整数相除可能截断小数，用 `1.0` 或 `CAST(... AS numeric)` 保留小数。

利润率结果是比例，例如 `0.25` 表示 25%；只有需要直接显示 25 时才乘以 100。

## NULL 与空字符串

`NULL` 表示没有值，`''` 表示长度为零的字符串，两者不同。普通运算中，只要一边是 NULL，结果通常也是 NULL。

```sql
revenue - COALESCE(cost, 0)
```

将缺失成本按零处理。这是业务规则，只有确实允许时才这样写。

```sql
COALESCE(NULLIF(store, ''), '未填写')
```

将 NULL 和空字符串都替换为“未填写”；只含空格的字符串不会被这个表达式当成空字符串。

## 避免除零

```sql
revenue * 1.0 / NULLIF(quantity, 0)
```

数量为零时返回 NULL，不会因为除零中断查询。不要为避免空值直接把分母改成 1，这会改变计算口径。

## 条件判断

```sql
CASE
    WHEN revenue > cost THEN '盈利'
    WHEN revenue = cost THEN '持平'
    WHEN revenue < cost THEN '亏损'
    ELSE '数据缺失'
END
```

结果是分类文本，角色选择 **维度**，类型选择 **text**。这里单独处理了 NULL 导致无法比较的情况。

## 数值处理

```sql
ROUND(CAST(revenue AS numeric), 2)
```

保留两位小数。其他常见函数包括 `ABS(cost)`（绝对值）、`CEIL(price)`（向上取整）、`FLOOR(price)`（向下取整）。

## 文本处理

| 用途 | 表达式 |
| --- | --- |
| 拼接 | `CONCAT(store, '-', platform)` |
| 去两端空格 | `TRIM(store)` |
| 转小写 | `LOWER(platform)` |
| 转大写 | `UPPER(platform)` |
| 替换 | `REPLACE(store, '旗舰店', '')` |
| 截取前四个字符 | `SUBSTRING(order_no FROM 1 FOR 4)` |
| 字符长度 | `LENGTH(store)` |

## 日期处理

```sql
DATE_TRUNC('month', order_time)
```

截断到月份，结果仍为时间类型，适合按月分析。角色选择 **时间**，类型选择 **datetime**。

```sql
EXTRACT(YEAR FROM order_time)
```

提取年份。原始值是文本时，需要先进行类型转换，例如 `CAST(order_time AS timestamp)`；非法日期文本会使查询失败。

## 列名与引号

普通小写列名直接填写：

```sql
revenue - cost
```

空格、保留字或需要保留大小写的列名使用双引号：

```sql
"Sales Amount" - cost
```

点击可用列时系统会选择合适的引用方式。已有公式编辑时可能显示系统规范化后的双引号，这是正常的。

文本值使用单引号，例如 `'盈利'`；双引号表示列名，不能混用。公式引用的是来源列名，而不是已有字段修改后的显示名称。

## 角色与限制

| 角色 | 适用结果 |
| --- | --- |
| 维度 | 平台、销售等级等分类 |
| 时间 | 日期、月份等时间值 |
| 度量 | 利润、数量等可计算数值 |
| 标识 | 用于识别记录的编码，只支持计数或去重计数聚合 |

- 支持逐行表达式及已开放的常用内置函数，不支持自定义函数。
- 不支持完整查询、子查询、聚合函数、窗口函数或引用另一个公式字段。
- `SUM(revenue)` 等汇总计算应在 **指标** 中配置。
- 不允许通过公式读取已设置脱敏规则的源列。
- 本地副本表先同步源数据，再由查询计算公式；公式不会触发数据同步。
- 直连模式会转换为源数据库方言，函数是否可执行仍取决于源数据库。
- **导入 / 导出配置 → 明策配置 JSON** 会携带公式，导入目标必须具有对应源列。
- 复杂公式、大量数据或公式参与排序分组时，会增加查询开销。
