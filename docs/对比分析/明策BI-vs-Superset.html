怎么用这张表

如果目标是「自己公司用」

选明策BI。18 项 = 赢 7 项、平 1 项、输 10 项，但赢的全在你每天要用的地方：看板好不好看、AI 能不能直接出图、权限能不能卡到部门、数据会不会漏、外传能不能追到人；输的多是「平台能力」，自用场景用不满。

如果目标是「做产品卖给别人」

Superset 仍领先 2.4 分。40+ 连接、插件体系、i18n、嵌入 SDK 是碾压级的；你要接 Snowflake / BigQuery 客户、要白标嵌入，自研至少一年。

互补，而不是二选一

Superset 当「取数与探索层」（SQL Lab + 云数仓直连），明策当「交付层」（设计看板 + 权限 + AI + 水印）。中间用物化表或 API 对接，两边优势都拿到。

本版之后，最该补的三件事

① SSO/IAM（R15，接钉钉/企微/飞书/OIDC —— 权限 93 分的唯一硬伤）；② 云数仓连接器（Snowflake/BigQuery）；③ 组件与数据源的注册式扩展，把「改 5 处代码」变成「装一个包」。
