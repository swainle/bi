## 五条关键差异

1. **看板编辑 +21（最大领先）**：明策 1440 版面自由拖拽 + 撤销栈 + 分平台套 + AI 排版 + 窄卡自适应；Superset 是行/列网格拼装，无自由叠加、无撤销。
2. **可拓展性 −19（最大落后）**：Superset 有可视化插件、engine spec、Extensions 框架；明策本版补了「组件开发规范 + 数据契约 + 23 个真实 fixture」，渲染器可外发分包开发，但仍不是插件体系。
3. **连接器 −18**：Superset 40+ dialect（Snowflake/BigQuery/Databricks/Athena/Druid）；明策 15 类，多一个人大金仓（国产化）。
4. **数据安全 +15**：明策本版新增身份水印、敏感字段自动脱敏、卫士 v2、MCP 数据分级预算；Superset 只有 RBAC + RLS 模板。
5. **权限 +11 但缺 SSO**：明策有部门树/数据范围/审批流/凭据治理，但没有 OAuth/LDAP/SAML —— R15 是权限项唯一硬伤。

## 选型建议

- **自家公司用** → 明策BI。赢的 7 项全在日常动线；输的 10 项多在「平台能力」，自用场景用不满。
- **做产品卖别人** → Superset。40+ 连接、i18n、嵌入 SDK 是碾压级，自研至少一年。
- **互补**：Superset 做取数探索层（SQL Lab + 云数仓），明策做交付层（设计看板 + 权限 + AI + 水印）。
- **明策最该补**：① SSO/IAM（R15）；② 云数仓连接器；③ 组件与数据源的注册式扩展。

## 口径说明

评的是能力覆盖、工程成熟度、中文企业自建场景适不适合，不是绝对代码质量，也不是性能 benchmark。
85.3 : 85.1 统计上是平手，结论看结构不看总分：明策赢治理深度（安全/权限/指标/AI），Superset 赢平台广度（连接/扩展/底座）。
