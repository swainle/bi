| `certifi` | MPL-2.0 | CA 证书数据文件，未修改；文件级弱 copyleft |
| `orjson` | MPL-2.0 AND (Apache-2.0 OR MIT) | 二进制 JSON 扩展，未修改；保留声明 |

- 未发现 GPL / AGPL / SSPL / Commons Clause 依赖。
- 全量核对命令（在新环境执行）：

```bash
cd backend && ./.venv/bin/python - <<'PY'
from importlib.metadata import distributions
for d in distributions():
    m = d.metadata
    lic = m.get("License-Expression") or m.get("License") or ""
    print(m["Name"], d.version, lic.splitlines()[0] if lic else "UNKNOWN")
PY
```
